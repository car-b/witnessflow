### Sources

- **Levine-32** (bone marrow, mass cytometry; Levine et al., Cell 2015; Weber and Robinson, Cytometry A 2016):
  https://github.com/lmweber/benchmark-data-Levine-32-dim, folder `data/`.

      python tools/fetch.py https://raw.githubusercontent.com/lmweber/benchmark-data-Levine-32-dim/master/data/Levine_32dim_notransform.fcs data/raw/Levine32/Levine_32dim_notransform.fcs
      python tools/fetch.py https://raw.githubusercontent.com/lmweber/benchmark-data-Levine-32-dim/master/data/population_names_Levine_32dim.txt data/raw/Levine32/population_names_Levine_32dim.txt

- **WINGMEN** (PBMC, mass cytometry; trial NCT05110495): figshare, doi:10.6084/m9.figshare.30174547.v1, CC BY 4.0.

      python tools/fetch_figshare.py 30174547 data/raw/WINGMEN
      python tools/verify_md5.py data/raw/WINGMEN

- **CytoNorm example data** (Van Gassen et al., Cytometry A 2020): https://github.com/saeyslab/CytoNorm, folder
  `inst/extdata`, files `Gates_PTLG021_Unstim_Control_1.fcs`, `..._2.fcs` and the same for PTLG028 and PTLG034.

      python tools/fetch.py https://raw.githubusercontent.com/saeyslab/CytoNorm/master/inst/extdata/Gates_PTLG021_Unstim_Control_1.fcs data/raw/CytoNorm/Gates_PTLG021_Unstim_Control_1.fcs

S1 Table (sheet Files) lists every file with its role in the analyses.

## La Jolla coverings: `ljcr_snapshot_subset.sqlite`

216 coverings (152 KB) with t = 3, v <= 32 and k <= 12, copied row by row without change from the snapshot of the
La Jolla Covering Repository (version 1.2) used in the study (identifier `ljcr_snapshot_db` in the manifests). Table
`covers(v, k, t, size, source, blocks)`; `blocks` holds size x k unsigned 8-bit point labels, read by `ljcr_blocks()` in
`src/design.py`. The code reads this file by default; set `WITNESSFLOW_LJCR_DB` to use a complete snapshot with the same
layout. The values used in the article are also listed in S3 Table.

Source and licence: La Jolla Coverings Repository, version 1.2, D. Gordon, archived at Zenodo (doi:10.5281/zenodo.19735294),
CC BY 4.0. The coverings are unchanged; the selection and the SQLite format are ours.
